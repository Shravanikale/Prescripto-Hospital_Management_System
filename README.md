
# 🏥 Prescripto – Hospital Management System

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fprescripto-hospital-management-syst-alpha.vercel.app%2F)](https://prescripto-hospital-management-syst-alpha.vercel.app/)

[![Deployed on Vercel](https://img.shields.io/badge/Frontend-Vercel-black?logo=vercel)](https://vercel.com/)

**Prescripto** is a modern, responsive, and scalable **Hospital Management System (HMS)** built using the **MERN stack**. It streamlines hospital operations by managing patients, doctors, appointments, prescriptions, and more — all through a clean and intuitive interface.

## 🔧 Local Setup

```bash
# Clone the repository
git clone https://github.com/yourusername/prescripto-hospital-management-system.git

# Navigate into the directory
cd prescripto-hospital-management-system

# Install dependencies
npm install

# Start the development server
npm start
```

## 🚀 Deployment (Vercel)

To deploy the frontend:

1. Push your project code to GitHub  
2. Visit [https://vercel.com](https://vercel.com) and sign in with your GitHub account  
3. Click on **“New Project”** and import your GitHub repository  
4. Configure the following settings:
   - **Framework Preset**: React (or select based on your setup)
   - **Build Command**: `npm run build`
   - **Output Directory**: `build`
5. Click **Deploy**  
6. Once deployed, you'll receive a live link to access your app 🎉
